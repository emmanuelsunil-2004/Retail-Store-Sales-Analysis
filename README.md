# Retail Store Sales Analysis

## Project Overview
This project analyzes retail store sales data using Python. The objective is to understand customer purchasing behavior, evaluate discount effectiveness, and extract meaningful business insights using exploratory data analysis (EDA).

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Phases
1. Problem Definition
2. Data Cleaning
3. Data Preparation
4. Exploratory Data Analysis
5. Business Insights and Conclusion

## Key Insights
- Discounts positively impact customer spending.
- Certain product categories generate higher revenue.
- Sales performance varies across locations.
- Customer spending is influenced by price and quantity.

- Sales forecasting using machine learning
- Customer segmentation
